# سایه — خرید آنلاین (نسخه موبایل، تبلت و دسکتاپ)

## فایل‌ها
- `index.html` ساختار صفحه
- `style.css` استایل‌ها و ریسپانسیو
- `app.js` منطق سایت (صفحه‌ها، سبد خرید، پرداخت، پنل ادمین)

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای انتشار، سه فایل را در کنار هم روی هر هاست استاتیک (مثل Netlify، GitHub Pages یا هاست معمولی) قرار دهید.

## صفحه‌ها
خانه، دسته‌بندی‌ها، سبد خرید، حساب کاربری، جزئیات محصول، جستجو، پرداخت، پنل ادمین.

## ادمین
- ایمیل ادمین در ابتدای `app.js` با ثابت `DEV` تعریف شده است.
- ادمین با ورود به حساب کاربری با همین ایمیل به پنل دسترسی پیدا می‌کند (`#/dev`).
- امکانات: افزودن و حذف محصول، مدیریت دسته‌بندی‌ها، سفارش‌های پرداخت‌شده، دکمه «ارسال شد» و صفحه سفارش‌های ارسال‌شده (`#/dev/shipped`).

## نکات مهم
- همه اطلاعات (محصولات، سبد، سفارش‌ها، دسته‌ها، تم) در `localStorage` مرورگر ذخیره می‌شود و بین کاربران مشترک نیست.
- ثبت‌نام و ورود با ایمیل و رمز عبور انجام می‌شود. رمز به‌صورت هش‌شده (PBKDF2 با salt) فقط در مرورگر ذخیره می‌شود، اما حساب‌ها بین دستگاه‌ها مشترک نیستند و چون بک‌اند وجود ندارد، قفل پنل ادمین امنیت واقعی ندارد.
- صفحه پرداخت آزمایشی است. برای پرداخت واقعی باید به یک درگاه (مثل زرین‌پال یا زیبال) و یک سرور متصل شود تا مبلغ ارسال و پرداخت تأیید شود.
- برای فروش واقعی و ذخیره مشترک اطلاعات، به بک‌اند و دیتابیس نیاز است.
